# DVB-Wandertipps – Übersichtskarte

Statische, interaktive Übersicht der 27 DVB-Wandertipps für Dresden und Umgebung. Die Karte zeichnet die offiziellen GPX-Tracks aus `tracks/`; die An- und Rückfahrtinformationen stammen aus den jeweiligen DVB-Tourseiten in `data/routes.json`.

## GitHub Pages veröffentlichen

1. Dieses Verzeichnis in ein neues GitHub-Repository hochladen.
2. In **Settings → Pages** unter **Build and deployment** die Option **Deploy from a branch** wählen.
3. Den Branch `main` (oder `master`) und den Ordner `/(root)` auswählen und speichern.

Die Website ist anschließend unter `https://<github-name>.github.io/<repository-name>/` erreichbar.

Die Linien dienen nur als geografische Übersicht. Für Navigation, aktuelle Inhalte und GPX-Dateien bitte die [DVB-Wandertipps](https://www.dvb.de/de-de/entdecken/wandertipps) nutzen.
